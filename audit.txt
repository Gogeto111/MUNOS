========================================
NEW FEATURES IN THIS SESSION
========================================

1. AI ASSISTANT (MUN Command Center)
   - /assistant - Full chat interface with context setting
   - Quick actions: GSL 60/90/120s, POIs, Speech, Resolution, Strategy, Practice, News
   - Shift+Enter for newlines, auto-scroll, auto-focus
   - System prompt: 12 core principles, brutal honesty, real data mandate
   - GSL generator: Hook→Context→Position→Evidence→Proposal→Closing Hook
   - Humanized responses, timing markers, actionable feedback

2. RESEARCH AGENT (8-Page Dossier)
   - /research-agent - Comprehensive research generation
   - Page 1: Executive Brief (what/why/UN position/current situation)
   - Page 2: Country Position (policy/voting/treaties/alliances)
   - Page 3: Agenda Deep Dive (issues/causes/disputes/terminology)
   - Page 4: Other Countries (positions/allies/vulnerabilities)
   - Page 5: UN Framework (resolutions/charters/agencies)
   - Page 6: MUN Application (proposals/clauses/funding)
   - Page 7: Attack Material (contradictions/statistics/weaknesses)
   - Page 8: Sources (Tier 1/2/3 with credibility scores)
   - "Prepare Me for Debate" button → sends to AI Assistant

3. INSTAGRAM MUN DISCOVERY
   - /api/mun/discover - Instagram Graph API integration
   - Searches hashtags: mun, modelunitednations, harvardmun, mun2026, thimun
   - Filters MUN-related profiles automatically
   - Shows: name, bio, website, followers, profile picture
   - Rate limit protection (200ms between calls)
   - "Scan Instagram" button on Discover page

4. SITUATION ROOM
   - /situation-room - Live committee context
   - Breaking news, talking points, POIs, resolution implications
   - Country-specific analysis during sessions

5. VOICE AGENT (STT/TTS)
   - /api/stt - OpenAI Whisper speech-to-text
   - /api/tts - ElevenLabs text-to-speech
   - Server-side only (keys never exposed to browser)

6. PERSONAL AI MEMORY
   - UserAiMemory table in database
   - Stores: strengths, weaknesses, preferences, style
   - CRUD actions for memory management
   - AI uses memory for personalized feedback

7. MUN SCORING ENGINE
   - Scores: speaking, research, diplomacy, leadership, documentation, collaboration
   - 0-100 scoring with specific breakdowns
   - Biggest weakness + strongest moment analysis
   - Historical performance tracking

8. AI FALLBACK SYSTEM
   - Primary: Gemini → OpenAI → Anthropic → Groq
   - Automatic failover if provider is down
   - Configurable per environment

9. CUSTOM MUN CURSOR
   - 🔨 (gavel) for default cursor
   - 🙏 (pointing) for interactive elements
   - Applied site-wide via CSS

10. PRIVACY PAGE
    - /privacy - Full privacy policy
    - Covers: data collection, AI usage, storage, rights, cookies
